# Conventions from first-move, scope from the spec

`~/repos/private/first-move` works the same problem space, narrower, and this repo copied its conventions: laravel-data over API Resources, generated TypeScript, parallel Pest, no shame mechanics. Product scope, the domain model and priorities come from [the spec](../product-spec.md) alone, because it is the sharper statement of the intent; where the two disagree the spec wins and first-move is not consulted.
