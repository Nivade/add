# One capture box, and the model sorts it

Capture is one text box with no required fields. The model sorts each capture into a kind inside the same `parse_capture` answer, home reads the kind back marked as inferred, and one tap changes it. This reversed slice 9's separate entry dialogs (2026-09-30), because choosing where a thought goes is exactly the deciding this product exists to remove. Long text (over 280 characters, or containing a blank line) goes to the ingestion classifier from the same box, by a deterministic length rule.

AI consent is therefore asked at signup and required to register (2026-10-01), reversing slice 8's opt-in; withdrawing it stays possible, and a capture the model cannot sort is marked failed and home says so. There is no model-free path.

## Considered options

- Kind chips in the capture dialog: too busy.
- A deterministic phrase router for kinds: the person chose the model.
- A second model call to ask the kind: one payload is never sent twice.
- A model-free sort for people without consent: the app works because of the model.
